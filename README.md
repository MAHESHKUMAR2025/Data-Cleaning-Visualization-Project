# Data-Cleaning-Visualization-Project

## 📌 Project Overview
This project focuses on cleaning, preprocessing, and visualizing the Titanic dataset using Python. The goal is to transform raw data into meaningful insights through data analysis and visualization techniques.

---

## 🎯 Objectives
- Handle missing values
- Remove duplicate records
- Detect and remove outliers
- Perform Exploratory Data Analysis (EDA)
- Create visual reports and charts
- Learn storytelling with data

---

## 📂 Dataset
Dataset Used: Titanic Dataset

The dataset contains passenger information such as:
- Age
- Gender
- Passenger Class
- Fare
- Survival Status

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## ⚙️ Features Implemented

### ✅ Data Cleaning
- Filled missing values
- Removed duplicate rows
- Handled outliers using IQR method
- Removed unnecessary columns

### ✅ Data Visualization
Created visualizations such as:
- Survival Count Plot
- Gender vs Survival Analysis
- Age Distribution Histogram
- Passenger Class Distribution
- Fare Boxplot
- Correlation Heatmap

---

## 📊 Visualizations

### Survival Count
Shows the number of passengers who survived and did not survive.

### Gender vs Survival
Analyzes survival rates based on gender.

### Age Distribution
Displays passenger age distribution.

### Correlation Heatmap
Shows relationships between numerical features.

---

## 📖 Key Insights
- Female passengers had a higher survival rate.
- First-class passengers survived more compared to other classes.
- Most passengers were between 20–40 years old.
- Higher fare passengers had better survival chances.
